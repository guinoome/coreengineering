# CORE Integrated Engineering

Official website — engineering consultancy serving Cebu and Southern Leyte, Philippines.

## Stack

- React 18 + Vite 5
- Fonts: Sora (headings) + Inter (body) via Google Fonts
- GitHub Pages via GitHub Actions

## Local Development

```bash
npm install
npm run dev
```

## Enable GitHub Pages

Go to **Settings → Pages → Source** and select **GitHub Actions**.

After one successful push to `main` the site will be live at:
https://guinoome.github.io/coreengineering/
